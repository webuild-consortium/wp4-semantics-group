# WE BUILD WP4 Semantics Group

Driven from the needs of the use cases, the Semantics Group is creating the semantic model for the WE BUILD project.

Github is used for creating the vocabulary including datamodel and ontology, classes, properties and some other aspects of the semantic model.

The latest version is published here: https://w3id.org/ebwv

The nordics interoperability platform is used for defining the concepts. Links are included in the vocabulary.

More information see the Semantics Group's café on the webuild portal: https://portal.webuildconsortium.eu/group/semantics/about

## Ontology editing with Protégé

The draft ontology for joint development starts in [semantics/model/webuild.ttl](semantics/model/webuild.ttl). The extension uses ontology IRI `https://w3id.org/ebwv/semantic-model` and term namespace `https://w3id.org/ebwv/semantic-model#` (`ebwsm:`); reused published EBWV terms retain their existing IRIs. Read the [current decisions and open questions](semantics/MODEL_STATUS.md) for the consolidated model status. The workflow and open governance decisions are recorded in the [Protégé and GitHub working guide](semantics/PROTEGE_GITHUB.md). Earlier model files are preserved in [Archive](semantics/model/Archive).

Use-case links and modelling rationale are maintained outside the ontology in the [use-case traceability register](semantics/USE_CASE_TRACEABILITY.md).
